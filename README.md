# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date:15/10/2026

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE

 ### STEP-1:  Start the sketch command

   Select Sketch > Create Sketch.
   <img width="1200" height="1600" alt="1" src="https://github.com/user-attachments/assets/b2c162f6-afbf-4875-a343-6e75c364ca84" />


 ### STEP-2:  Select the Sketch Plane

   Select the Front (XZ) Plane
   <img width="1487" height="883" alt="Screenshot 2026-11-17 155438" src="https://github.com/user-attachments/assets/1edaa5c9-0078-475e-9deb-d720803e8266" />


### STEP-3: Create a Rectangle 

   1.	Select Sketch > Rectangle > Center Rectangle.
   2.	Now hover over the origin (center) of the sketch. You should see the cursor snap to this location.
   3.	Click once to begin placing the rectangle.
   4.	Type the Tab button and enter the values 100 mm and 60mm for the width and height respectively.
   5.	Click again to place the rectangle.
   6.	Click Finish Sketch after completing.
    <img width="1486" height="886" alt="Screenshot 2026-11-17 155636" src="https://github.com/user-attachments/assets/03ccf201-32a0-4133-b54f-7fe4148c212a" />
  

 ### STEP-4: Extrude Rectangle in XZ Plane
   1.	Select Extrude.
   2.	Select the Rectangle sketch.
   3.	Click again to place the value.
   4.	Type in the value of 30mm. 
   5.	Press ENTER to accept the value.
   	<img width="1490" height="854" alt="Screenshot 2026-11-17 155726" src="https://github.com/user-attachments/assets/7310a37c-3580-46c4-b839-cd8eb128e8a0" />


 ### STEP-5:  Start the sketch command
   Select Sketch > Create Sketch.
   <img width="1200" height="1600" alt="1" src="https://github.com/user-attachments/assets/4399fcf2-1e99-445d-b778-0bf82613555e" />

 ### STEP-6: Select the Sketch Plane
   Select the FRON SURFACE of rectangular block
<img width="1478" height="840" alt="Screenshot 2026-11-17 154623" src="https://github.com/user-attachments/assets/d3118c83-0e73-4497-a01f-d482058a4f96" />

 ### STEP-7: Create a CIRCLE 
   1.	Select Sketch >CIRCLE  > CENTER CIRCLE.
   2.	Now hover over the origin (center) of the sketch. You should see the cursor snap to this location.
   3.	Click once to begin placing the CIRCLE.
   4.	Type the Tab button and enter the value DIA 100mm .
   5.	Click again to place the circle.
   6.	Click Finish Sketch after completing.
   	<img width="1485" height="903" alt="Screenshot 2026-11-17 155110" src="https://github.com/user-attachments/assets/fdfab972-5dca-4ed6-9ac7-8ed5d85e9753" />


 ### STEP-8:  Extrude CIRCLE 
   1.	Select Extrude.
   2.	Select the Rectangle sketch.
   3.	Click again to place the value.
   4.	Type in the value of 20mm. 
   5.	Press ENTER to accept the value.
   	<img width="1492" height="879" alt="Screenshot 2026-11-17 155947" src="https://github.com/user-attachments/assets/0008c674-5746-4538-a25c-5ac41f43e5f3" />

 ### STEP-10: Select the Sketch Plane
